# Hermes Calendar

Integración privada de uso personal. Conecta mi propio asistente (Hermes Agent, alojado en mi casa) con mi propio Google Calendar para crear y consultar eventos.

No es un servicio público: la usa una sola persona, su propietario. No hay registro ni acceso para terceros.
